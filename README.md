
# DevFolio - Backend

A full-stack developer portfolio platform built with Django and Django REST Framework. This backend provides REST APIs to manage portfolio content, authentication, projects, blogs, and contact messages.

## 🚀 Project Overview

DevFolio is a personal portfolio web application designed to showcase development skills, projects, experience, and professional information.

## 🛠️ Technologies Used

- Python
- Django
- Django REST Framework
- SQLite / PostgreSQL
- REST API
- Git & GitHub

## ✨ Features

- User Authentication
- User Registration and Login
- Portfolio Management
- Project Management
- Blog Management
- Contact Message Management
- RESTful API Integration

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/shaown-roy-cse/devfolio-backend.git
```

### 2. Navigate to the Project

```bash
cd devfolio-backend
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply Migrations

```bash
python manage.py migrate
```

### 7. Run Development Server

```bash
python manage.py runserver
```

Backend server:

`http://127.0.0.1:8000/`
